# projet-cnn-cifar10
rojet présente l'utilisation d'un réseau de neurones convolutif (CNN) avec TensorFlow/Keras pour classifier des images en couleur parmi 10 catégories d'objets (avions, voitures, oiseaux, chats, cerfs, chiens, grenouilles, chevaux, bateaux, camions) à partir du jeu de données CIFAR-10.
